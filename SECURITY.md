# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Write to
**webmaster@nilumio.com** with a description, the affected version and, if possible,
steps to reproduce. You will get an answer within a few days.

If the problem also exists in [Swiftfin](https://github.com/jellyfin/Swiftfin) or in
Jellyfin itself, please report it there as well (Jellyfin:
https://jellyfin.org/docs/general/contributing/security/).

## Supported versions

Only the latest release of nilumio receives security fixes.

## Scope

nilumio talks only to the Jellyfin servers you add. Issues around stored tokens,
the keychain, server connections and SyncPlay groups are especially welcome.
